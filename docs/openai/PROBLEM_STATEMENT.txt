AI agents can produce valid tool calls after their authority has changed or after untrusted content has influenced a request. A credential alone does not establish that an action remains permitted. Lost acknowledgements also leave uncertainty about whether an effect already occurred. Evaluating model explanations or gateway labels without receiver state can conceal both unauthorized effects and useful work lost to enforcement.

Project Simurgh provides a host-controlled authorization boundary and a reproducible evaluation using synthetic tasks, matched credential-only/composed/deny-all controls, retained receiver snapshots and source-bound replay. Existing studies include live model proposals, native approval workflows, lifecycle changes and bounded recovery. Their internally authored tasks, retained failures and trusted-host assumptions limit generalization.

The proposed extension obtains independently authored cases and a separate operator reproduction, measuring new unauthorized effects, legitimate completion and evidence inconsistencies without dropping refusals, errors or unknown outcomes. It does not establish general model safety, truthful execution from signatures alone, protection for untested integrations or production readiness. The public evidence enables a reviewer to challenge each bounded claim without making a new paid model request.

AI agents can produce syntactically valid tool calls that exceed a user's authority after processing untrusted content. Developers often evaluate model responses or a gateway's own logs without independently checking whether prohibited effects occurred or authorized work still completed. Signed logs can expose later alteration, but signatures alone do not establish truthful execution, complete recording, or informed human approval.

We propose a reproducible defensive evaluation of tool authorization boundaries using synthetic tasks, local controlled effects, positive and negative controls, a deliberately vulnerable comparison, and a separate consequence checker. A deterministic offline mode tests the instrument without credentials; an optional, explicitly authorized OpenAI Responses API experiment would measure model-generated proposals against the same boundary. Portable signed artifacts support offline checking with an explicit trust model.

The result will quantify unauthorized effects, legitimate-task completion, and evidence inconsistencies for a declared case set, including failures and exclusions. It will not establish general model safety, independent provenance from a self-generated key, or protection for integrations that were not tested.

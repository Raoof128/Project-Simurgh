## Important boundaries in the source review

- The visible grant form includes a notice that OpenAI may independently develop similar ideas and owes no exclusivity. Owner review must include this notice and any terms presented during the actual submission process.
- The fetched visible form did **not** establish the pasted text's specific eligibility/export-control representations. Their precise wording and applicability remain **unverified** and require owner review; this package does not certify eligibility.
- The pasted text refers to an April 2026 update but supplies no exact source. That specific attribution was **not verified** and is not used to justify this proposal. The February update and current form above were retrieved directly.
- Agent-safety examples include particular model families. Examples do not establish account access, current pricing, best model choice, or availability at execution time. The live model ID is an explicit owner-selected configuration, with returned model metadata recorded by the adapter.
- Documentation retrieval verifies the published API shape, not a successful authenticated call or a provider's treatment of any specific request. No live interoperability or OpenAI-model security result is claimed.
- Some initial `urllib` requests to `openai.com` returned HTTP 403; ordinary `curl` GET requests retrieved the listed official pages successfully. The research used those returned pages without changing TLS verification.

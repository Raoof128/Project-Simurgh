# Case authorship

These 24 synthetic cases were authored by a separately tasked agent from the fixed interface and schema supplied in its task. The author did not inspect repository code, prior conversations, prior cases, or model outputs and did not spawn other agents.

The set contains 12 benign cases and 12 prompt-injection attack cases across exactly six families. Each family has two benign and two attack cases. All scenarios, documents, approvals, and transcripts are fictional. Benign references contain inert quotations, historical examples, or test specimens; the trusted task still states an exact public-read and literal-write goal. Attack references attempt to redirect that goal.

The author checked case counts, family balance, unique IDs, permitted output resources, and the ASCII and length constraints on expected content. No evaluation results informed authorship or case selection. All 24 authored cases are supplied for retention before evaluation.

Method: separate-agent-no-implementation-access. Limitation: same project and AI tooling; not external human independence.

# Record of corrections

This page lists the occasions on which the project's evidence, its audits or a replay showed that
something the project had claimed, expected or built was wrong, and what the project did about
it. Each entry links to the record that carries the detail. The page is an index into existing
records and adds no evidence.

Read it before deciding how far to trust the repository's numbers. It shows how the project found
its errors and what it did with them.

## Defects that independent replays found

These replays were run apart from the session that produced the evidence: three by the owner's
reviewer on machines the owner controls, and three by outside operators. Every replay that could
run the verifiers reproduced the committed results; one, natively on Windows, could run none of
them. Every replay also found something wrong with the instructions, the tools or the tests,
which the producing session's own runs had not. The first outside receipt discloses that an AI
coding agent on a subscription registered to the author typed the commands. The owner asked all
three outside operators. A review can establish what the returned outputs say and cannot
establish who produced them.

## What is still open

The project knows about these and has not repaired them.

- Every attacker that knew the gate is a Claude agent the author started (lanes 19t, 19y, 19z, 19ac, 19ae and 19ag). No attacker from outside the project has been run.
- One outside operator has replayed the manuscript's studies on a Linux machine. A second Linux host has not, and twenty newer handoff items are still owed.
- The frozen gate and the gates of lanes before 19ag still raise on a body without its `run` or `id`. Two recorded attempts that reach the gate's own stores still raise on the repaired gate, as they did on lane 19ae's.
- Several findings of the October documentation audit remain open; the [final validation](documentation-audit-2026-10-19/FINAL_VALIDATION.md) points to the manual register for open runtime gaps.
- No researcher outside the project has reviewed the manuscript.
- The 12 November documentation check left 645 confirmed findings open, most of them in dated
  records, and they are [listed](documentation-audit-2026-11-12/FINDINGS.md). Private values it
  redacted from the current files remain in git history, and five outside reviewers' signed
  blocks still carry the email address each reviewer declared.

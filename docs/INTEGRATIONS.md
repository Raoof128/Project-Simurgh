# Integration and evidence matrix

**Reviewed: 19 October 2026.** This matrix describes the repository's implemented surfaces,
recorded validation and unsupported extensions. “Integrated” means the named path was exercised
under the linked experiment; it does not mean arbitrary provider, tool or deployment compatibility.
Use [CONTRIBUTING](../CONTRIBUTING.md) for setup and [the reviewer guide](REVIEWER_INDEX.md)
for study-specific denominators.

merely because documentation now links a newer receipt.

## Operational handoff

Use the [owner/classmate handoff](research/CONTINUATION_HANDOFF_2026-10-19.md) for independent
reproduction. It separates current-branch replay from old downloadable bundles. Supply public
commit/root identifiers through a trusted channel; never put credentials in a review receipt.
Keep unknown effects, failures and unsupported capabilities explicit. A stop prevents admission
under the tested contract; it cannot reverse an already completed effect.

## Authority and boundaries

Current entry points outside frozen surfaces may be edited for accuracy and navigation. New
files belong in this audit directory and current documentation guides. `AGENT.md` and
`CHANGELOG.md` receive append-only entries. No stage-owned verifier, test, gate, specification,
protocol, capture, hash root or research result is authorized for mutation by this declaration.
If a correction requires such a change, use an additive erratum; any eventual runtime repair
needs its own stage-specific authority. This audit installs no CI gate and changes no existing
check or formatter exclusion.

A source checked in 2026 is not necessarily published in 2026. Separate standards, normative
protocol requirements, vendor guidance and project interpretation. Do not claim universal
standards compliance, scientific novelty, independent custody, browser accessibility or production
readiness from documentation work. No file count is a substitute for semantic review.
